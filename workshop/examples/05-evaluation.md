# Example: compare one instruction change

[Lab 4 comparison](../labs/04-handoff-review.md#46-compare-and-improve-one-instruction)
| [All examples](README.md)

Suppose a reviewer finds missing checks, but does not make clear that it did not
run them. Try this single addition:

```text
End each review with three short lines: what I inspected, what I did not run,
and what the human should check next.
```

Repeat the same normal and boundary prompts from Lab 4 in fresh chats.
Keep the model, tools, source context and task wording unchanged.
Compare the answers in place.

A useful change makes the human's next action clearer without invented execution
or broader permissions. Keep it only if it helps.
If the earlier instruction already works, no change is required.
Two tasks do not establish broad reliability.

No scores, copied responses, snapshots or evaluation file are needed.
