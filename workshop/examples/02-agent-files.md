# Example: starter agent files

[Lab 2](../labs/02-agent-design.md) | [All examples](README.md)

Lab 2 contains complete copy-and-paste blocks and explains where each goes.
These reusable templates provide the same starter roles:

- [QueuePlanner](../templates/planner.agent.template.md)
- [QueueReviewer](../templates/reviewer.agent.template.md)
- [Scoped test instructions](../templates/tests.instructions.template.md)

Open a template and copy its contents, including the `---` header, into the
path named in Lab 2. Do not copy the Markdown backticks.
Templates are inactive in this folder.

They target the VS Code **Local** harness.
Check the loaded tools after selecting the role. A profile that says "read-only"
is not a substitute for restricting actual tools.
No job-description file, starting-commit form or copied test output is required.
