# Example: hand off a task, not a folder of notes

[Lab 4](../labs/04-handoff-review.md) | [All examples](README.md)

Use the complete paste-ready task in
[Lab 4 Step 2](../labs/04-handoff-review.md#step-2-hand-off-a-complete-task).
It supplies the outcome, files, contract, tool limits and next action.
A fresh agent does not need your earlier conversation.

A useful review finding might say:

> The creation check asserts 201 but not Location or the returned record.
> Add assertions for `/tickets/5`, the trimmed title, server-owned ID and open status.
> Fetch the new ticket and compare it with the response.

This is illustrative advice, not a finding about code that has been implemented.
The human inspects the actual source and runs checks before accepting it.

Keep the task and answer in chat. Do not create a handoff report.
